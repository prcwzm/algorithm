# LeetCode Hot 100：20 天计划

版本：2026-07-21。题目以力扣官方「热题 100」学习计划为准，每天 5 题，共 100 题。

## 执行规则

1. 每题先写思路、复杂度，再编码；单题首次尝试限时 30 分钟。
2. 每题至少写 3 个测试：标准、边界、易错用例。
3. 每天标记：`[ ] 未开始`、`[~] 需复习`、`[x] 已掌握`。
4. 第 5/10/15/20 天末尾，用 30 分钟复盘错题并盲写一道题。
